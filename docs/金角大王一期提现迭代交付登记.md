### 2.3 V2.1 关键约束（继承自本期决策）

1. **绝对不改提现主流程**：发起 / 驳回 / 审核 / 打款 / 失败 5 流程的状态机、余额联动顺序、幂等锁、缓存失效逻辑——锁定不变，V2.1 仅修改「入账资金来源拆分」和「新增释放定时任务」。
2. **frozen_balance 语义不变**：仅用于提现审核锁定；保证金逻辑完全独立使用 `margin_balance`，避免语义混淆。
3. **提现可用余额**：V2.0 已仅消费 `available_balance`，保证金冻结期间自然不可提现，V2.1 仅需在入账处拆分，无需改提现校验。
4. **读穿缓存**：`UserCommissionAccountDAO.get_account_cached` 返回字段需新增 `margin_balance` 键；commit 后缓存失效逻辑不变，缓存结构自然回填新字段。
