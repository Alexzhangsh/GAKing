## 一、问题描述

`backend/start_prod.sh` 中 uvicorn 启动端口硬编码为 `--port 3001`，但 `.env.production` 配置的 `PORT=3003`（因服务器现有项目 xmyc26 占用 3001 端口，S04 时已改为 3003）。

**影响**：非 Docker 部署场景下直接执行 `start_prod.sh` 会启动在 3001 端口，与 `.env.production` 的 PORT=3003 配置不一致，导致服务端口与预期不符。

---

## 二、修复方案

### 修改前（硬编码）
```bash
python -m uvicorn src.main:app --host 0.0.0.0 --port 3001 --workers 4
```

### 修改后（动态读取）
```bash
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
ENV_FILE="$SCRIPT_DIR/.env.production"
PORT=$(grep -E '^PORT=' "$ENV_FILE" 2>/dev/null | cut -d'=' -f2- || echo "3001")
python -m uvicorn src.main:app --host 0.0.0.0 --port "$PORT" --workers 4
```

**修改的文件**：`backend/start_prod.sh`

**结果**：✅ 无语法错误

### 3.3 脚本执行验证（模拟）

**结果**：✅ PORT 变量正确加载为 3003

### 3.4 回退测试

**默认值兜底**：当 `.env.production` 中无 `PORT=` 配置时，`grep` 返回空，`|| echo "3001"` 兜底为默认值 3001。
