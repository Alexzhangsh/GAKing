## 七、待验收事项

1. **真实 Sentry 配置联调**：当前 `SENTRY_AUTH_TOKEN` 为空，渠道报错统计回退本地日志（`source=local_log`）。配置真实 Sentry Token / Org / Project 后，将切换为 `source=sentry` 从 Sentry 标签统计读取。
2. **渠道报错口径确认**：本地日志统计按 `[order_sync:xxx]` 前缀匹配渠道，Sentry 模式按 `channel` 标签聚合，两种口径需与业务确认一致。
3. **失败清单条数**：当前固定返回最近 20 条失败日志，如需分页可按需扩展。
