# 金角大王 线上数据库访问备忘

> 用途：给 Dev/QA/Release 查数、排障、对账用。**生产库只读优先，写操作走迁移流程**。

---

## 一、连接档案

| 项 | 值 |
|---|---|
| 地址 | `192.168.0.230:3306`（内网，公网不可直连） |
| 库名 | `gak` |
| 账号 | `gaking` |
| 密码 | 在服务器 `backend/.env.production` 的 `DB_PASSWORD`（禁止硬编码到脚本/文档；本机如需访问用 SSH 隧道读环境文件） |
| 字符集 | utf8mb4 |

## 二、访问方式

### 方式 A：服务器本地（推荐，只读/备份）
```bash
ssh -i <密钥> root@124.70.196.241
MYSQL_PWD="$(grep '^DB_PASSWORD=' /opt/gaking/backend/.env.production | cut -d= -f2-)" \
  mysql -h 192.168.0.230 -P 3306 -u gaking gak -e "SHOW TABLES;"
```

### 方式 B：本机 MySQL 客户端 + SSH 隧道（查数用）
```bash
# 终端 1：建立隧道（注意本机 3306 若被占用，换 13306）
ssh -i <密钥> -L 13306:192.168.0.230:3306 root@124.70.196.241 -N
# 终端 2：连接（密码从服务器 .env.production 读取）
mysql -h 127.0.0.1 -P 13306 -u gaking -p gak
```

## 三、端口转发陷阱（血泪）

- **本机 3306 冲突**：mac 本地若已装 MySQL/Docker 占用 3306，隧道必须换端口（如上 13306），否则连到的是本机库，**可能误操作**。
- **勿在生产库上跑测试脚本**：本地测试一律用 `.env.test` 的测试库；确认连接对象（`SELECT DATABASE(); SELECT @@hostname;`）后再执行写操作。
- **备份/恢复**：一律在服务器执行（`/opt/gaking/scripts/backup_db.sh` 已自动每日备份 + OBS 异地）；恢复演练用 OBS 备份恢复到隔离库，禁止在生产库演练。

## 四、常用查数（对账/排障）

```sql
-- 今日新增订单
SELECT COUNT(*) FROM <订单表> WHERE created_at >= CURDATE();
-- 提现申请待审核
SELECT COUNT(*) FROM user_withdraw_apply WHERE status='PENDING';
-- 对账差异定位（示例，按实际表结构）
SELECT order_id, commission_calc, platform_amount FROM <对账表> WHERE ABS(commission_calc-platform_amount) > 0.01;
```

> 表结构以 `backend/src/models/` 为准；修改数据一律通过迁移（`alembic revision`）或业务接口，禁止手改生产数据。
