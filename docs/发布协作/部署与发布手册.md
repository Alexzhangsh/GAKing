## 四、代码同步（发布用 rsync）

- 方向：本地 `GAKing-Coding/` → 服务器 `/opt/gaking/`
- **强制排除**：`.env.production`、`deploy/.env`、`*.pem`、`__pycache__`、`.git`（漏排除 = 密钥泄漏事故）
- 典型命令：`rsync -av --delete --exclude='.env.production' --exclude='deploy/.env' --exclude='.git' --exclude='*.pem' <本地目录>/ root@124.70.196.241:/opt/gaking/`
