## 二、生产铁律（违反即事故）

1. **先登记后发布**：批次未在 `发布步骤清单.md` 登记、交接单未过 `release_check.sh` 硬闸门，禁止上线。
2. **先建回滚点再动**：`docker tag ...:prod ...:prev` + 记录迁移版本 + 确认当日备份存在，缺一不动。
3. **敏感文件禁同步**：rsync 必须排除 `.env.production`、`deploy/.env`、`*.pem`；漏排除立即终止并检查密钥是否泄露。
4. **动生产库先暂停确认**：涉及生产数据库的迁移/脚本，执行前在批次清单标注并由 PM 确认；迁移失败立即 `alembic downgrade -1`。
5. **资金红线**：提现/打款**禁止自动重试**；对账差异 **0 容忍**，有差异先冻结提现再人工逐单核对（M07-3 §十）。
6. **发布后留观 30 分钟**：日志 ERROR / 任务成功率 / 对账状态异常，按 §四 处置。

---

## 三、资金相关变更附加检查（结算/提现/对账/会员权益，缺一终止）

| # | 检查 | 方法 |
|---|---|---|
| F-1 | 发布前手动对账 **0 差异** | 对账任务手动触发：渠道订单 vs 本地 vs 佣金 |
| F-2 | 资金类接口单测覆盖率 **100%** | pytest 覆盖率报告 |
| F-3 | 发布后 **2 小时内**人工对账复核 | 复核记录回填交接单 |

---

## 四、失败处置与回滚预案（任一环节失败）

| 失败点 | 处理 | 回滚 |
|---|---|---|
| 硬闸门/预检失败 | 终止发布，修复后重新核对 | — |
| 构建或迁移失败 | 立即回滚 | `docker tag gaking-backend:prev gaking-backend:prod && docker compose up -d`；`alembic downgrade -1` |
| 健康检查/生产验证失败 | 定位修复；无法短时修复则回滚 | 同上 |
| 留观期出现 ERROR/对账异常 | 按 M07-3 §八 故障 SOP 处置，必要时回滚 | 同上 |
| 同步后才发现漏排除敏感文件 | 立即终止 + 检查密钥泄露 + 轮换 | — |

---

## 五、发布完成定义

批次状态 = `已发布` **且** 满足：
- 发布单（`docs/发布单/REL-*.md`，Gate D/T/P 判定齐全）
- 运维台账已追加（`docs/S01-运维操作台账.md`：回滚点 tag、迁移版本）
- 留观 30 分钟通过，2h/24h 复核已排期
