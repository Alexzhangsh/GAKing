## 二、P0 阻断缺陷（已修复 + 二次复测验证）

### BUG-S07-01：C 端用户 ID 碰撞越权访问后台（权限漏洞）

| 字段 | 内容 |
|------|------|
| 严重级别 | **P0（阻断）** |
| 模块 | RBAC 权限链路 |
| 发现方式 | S07 权限链路复测 |
| 问题描述 | C 端用户 token（role_id=0）与后台管理员 ID 空间重叠，小程序用户 user_id=1 与后台超管 user_id=1 碰撞时，C 端用户可通过构造 token 越权访问后台管理接口 |
| 根因分析 | C 端与后台共用同一 JWT 密钥，且 RBAC 权限查询仅按 user_id 匹配，未校验 role_id，导致 ID 碰撞时 C 端 token 被误判为管理员 |
| 修复方案 | RBAC 工具方法 `get_user_permissions` / `has_permission` / `has_any_permission` / `has_all_permissions` 增加 `role_id` 参数，role_id=0（C 端）直接拒绝返回空权限；`require_permission` / `require_any_permission` 依赖从 payload 提取 role_id 并透传 |
| 修改文件 | `backend/src/common/auth_util.py`、`backend/src/common/b15_rbac_middleware.py` |
| 验证结果 | ✅ 单元验证 `s07_verify_rbac_fix.py` 4/4 通过（C端无权限/管理员有权限/默认安全拒绝）；线上权限隔离 10/10 接口全部 403 拦截 |
| 修复时间 | 2026-08-14 |

### BUG-S07-02：转链结果缺少推广链接返回 500 崩溃

| 字段 | 内容 |
|------|------|
| 严重级别 | **P0（阻断）** |
| 模块 | 商品转链（B01 渠道适配器） |
| 发现方式 | S07 小程序复测异常场景 |
| 问题描述 | 喵有券/订单侠转链接口返回结果缺少 promote_url（cps_short_url/cps_long_url 均为空）时，适配器直接使用空值导致 500 服务器崩溃 |
| 根因分析 | 适配器未校验转链 API 返回结果，未处理空推广链接场景 |
| 修复方案 | 校验 promote_url，为空时抛出结构化 `CpsChannelException`（error_type=API_ERROR），映射为 HTTP 502 业务错误并返回清晰错误信息 |
| 修改文件 | `backend/src/cps/adapter/miaoyouquan_adapter.py`、`backend/src/cps/adapter/dingdanxia_adapter.py` |
| 验证结果 | ✅ 小程序复测"链接转链-渠道异常结构化返回（无500崩溃）"通过，返回 502 + 清晰错误信息 |
| 修复时间 | 2026-08-14 |
