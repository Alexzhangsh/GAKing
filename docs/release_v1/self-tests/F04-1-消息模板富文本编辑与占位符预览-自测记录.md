## 4. 自测中发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | Vue 模板编译错误（Unexpected token） | 插值表达式 `{{ customPhName ? \`{{${customPhName}}}\` : '' }}` 中反引号与 Vue 模板解析冲突 | 改用 computed 属性 `customPhLabel` |
| 2 | el-tag 重复 closable 属性 | 静态 `closable` 与绑定 `:closable` 重复 | 移除静态属性，保留绑定 |
| 3 | wangEditor 报错 "Not found menu item factory by key 'strikethrough'" | wangEditor 5 删除线菜单 key 是 `through` 非 `strikethrough` | 修正为 `through` |
| 4 | wangEditor 报错 "key 'head'" | wangEditor 5 标题菜单是 `header1/2/3` 非 `head` | 改为分组 `group-head` |
| 5 | wangEditor 报错 "key 'image'" | wangEditor 5 图片上传菜单是 `uploadImage` 非 `image` | 修正为 `uploadImage` |
| 6 | wangEditor 报错 "key 'list/quote/link/video'" | wangEditor 5 对应 `bulletedList/numberedList`、`blockquote`、`insertLink`、`insertVideo` | 全部修正为官方 key |
