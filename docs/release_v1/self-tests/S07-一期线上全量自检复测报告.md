### 5.1 P0 阻断缺陷（已修复 + 二次复测验证）

| 编号 | 模块 | 问题描述 | 根因 | 修复方案 | 修复文件 | 验证结果 |
|------|------|----------|------|----------|----------|----------|
| BUG-S07-01 | RBAC 权限链路 | C 端用户 token（role_id=0）与后台管理员 ID 空间重叠，可通过 ID 碰撞越权访问后台接口 | C 端与后台共用 JWT 密钥，user_id 空间重叠（小程序 user_id=1 与超管 user_id=1 碰撞） | RBAC 工具方法增加 `role_id` 参数，role_id=0 直接拒绝，阻断 ID 碰撞越权 | `auth_util.py`、`b15_rbac_middleware.py` | ✅ 单元验证 4/4 + 权限隔离 10/10 全部 403 |
| BUG-S07-02 | 商品转链 | 喵有券/订单侠转链结果缺少 promote_url 时返回 500 崩溃 | 适配器未校验转链结果，空 promote_url 直接使用 | 校验 promote_url，为空时抛出结构化 `CpsChannelException` → 502 业务错误 | `miaoyouquan_adapter.py`、`dingdanxia_adapter.py` | ✅ 小程序复测"转链渠道异常结构化返回"通过 |
