## 六、回滚方案

### 6.1 代码回滚

```bash
git revert <上线commit>
```

### 6.2 数据库回滚

```bash
cd backend
alembic downgrade -1
```

### 6.3 Docker 回滚

```bash
cd deploy
docker compose down
docker tag gaking-backend:prod gaking-backend:prod-rollback-$(date +%Y%m%d)
# 拉取上一版本镜像后重新启动
```
