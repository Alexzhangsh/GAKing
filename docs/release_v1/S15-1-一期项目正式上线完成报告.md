## 一、任务概述

根据 S15-1 任务要求，完成以下工作：
1. 彻底移除后端 FastAPI、管理后台 admin、微信小程序 miniprogram 三处全部 Sentry 相关代码、初始化逻辑、import 导入
2. 删除环境配置文件内所有 SENTRY_DSN / VITE_SENTRY_DSN 相关配置项
3. 移除 requirements.txt、前端 package.json 里面 sentry-sdk 相关依赖包
4. 保留项目原有全局 Logger 日志打印体系不变，线上依靠 Docker 容器日志排查异常
5. 重启全部容器，验证服务启动正常，无 Sentry 相关报错
6. 执行一期上线最终全量验收
7. 输出一期项目正式上线完成报告
