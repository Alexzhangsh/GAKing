## 一、概述

### 1.1 部署架构

```
┌─────────────────────────────────────────────────┐
│                  生产服务器                        │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │  Redis   │  │ Backend  │  │  Admin   │       │
│  │ :6379    │  │ :3003    │  │ :80 → :8080     │
│  │ (容器内)  │  │ (容器内)  │  │ (容器内)  │       │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘       │
│       │              │              │              │
│       └──────────────┴──────────────┘              │
│                      │ 内部网络                      │
│                      ▼                              │
│             ┌────────────────┐                      │
│             │  MySQL RDS     │                      │
│             │  (华为云内网)   │                      │
│             └────────────────┘                      │
└─────────────────────────────────────────────────┘
```

### 1.2 服务端口映射

| 服务 | 容器端口 | 宿主机端口 | 说明 |
|------|---------|-----------|------|
| Redis | 6379 | 不映射（内网） | 仅 backend 容器内部访问 |
| Backend API | 3003 | 3003 | 供 Nginx 反向代理 |
| Admin 前端 | 80 | 8080 | 静态文件，Nginx 容器内服务 |

### 1.3 前置条件

- 服务器已开通，操作系统：CentOS 7+ / Ubuntu 20.04+
- 服务器可访问以下外部资源：
  - 华为云 MySQL RDS（内网地址）
  - 华为云 OBS 存储
  - 喵有券 API（需配置 IP 白名单）
  - GitHub / 代码仓库（拉取代码）
- 以下域名已备案并解析到服务器 IP：
  - `api.dftsh.top` → 后端 API
  - `admin.dftsh.top` → 管理后台
  - `img.dftsh.top` → 静态资源 CDN
- 第 1 次部署前需完成 S06-1 巡检清单中的全部待补填项

## 二、前置准备（第 1 次部署执行）

### 2.1 安装 Docker

```bash
# CentOS 7+
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable docker && sudo systemctl start docker

# Ubuntu 20.04+
sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable docker && sudo systemctl start docker
```

## 三、启动服务

### 3.1 执行前置校验

```bash
cd /data/apps/gaking
bash scripts/pre_deploy_check.sh --remote
```

确认所有检查项均为 `PASS`，无 `FAIL` 项。

### 3.2 构建并启动

```bash
cd /data/apps/gaking/deploy
docker compose up -d --build
```

### 3.3 查看启动状态

```bash
# 查看所有容器状态
docker compose ps

# 期望输出（3 个容器全部 healthy）：
# NAME                STATUS
# gaking-redis        Up X minutes (healthy)
# gaking-backend      Up X minutes (healthy)
# gaking-admin        Up X minutes (healthy)

# 查看实时日志
docker compose logs -f backend

# 查看 backend 启动日志（确认 Alembic 迁移成功）
docker compose logs backend | grep -E "alembic|migration|upgrade"
```

### 3.4 执行健康检查

```bash
cd /data/apps/gaking
bash scripts/health_check.sh prod
```

```bash
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```

## 六、数据库迁移

### 6.1 迁移执行顺序

```bash
# 进入 backend 容器
docker exec -it gaking-backend bash

# 查看当前迁移版本
cd /app  # 容器内工作目录
alembic current

# 升级到最新版本
alembic upgrade head

# 查看迁移历史
alembic history
```

### 6.2 迁移脚本清单（共 26 个）

| 版本 | 功能 | 执行状态 |
|------|------|----------|
| 0001 | 初始化所有表 | ✅ 已执行 |
| 0002 ~ 0025 | 各业务模块 | ✅ 已执行 |
| 0026 | 会员套餐和记录 | ✅ 已执行 |

### 6.3 回滚操作

```bash
# 回退一个版本
docker exec -it gaking-backend alembic downgrade -1

# 回退到指定版本
docker exec -it gaking-backend alembic downgrade <版本号>
```

## 七、日常运维命令

### 7.1 容器管理

```bash
# 查看所有容器状态
docker compose ps

# 查看实时日志
docker compose logs -f backend
docker compose logs -f admin

# 查看最近日志（最后 100 行）
docker compose logs --tail=100 backend

# 重启某个服务
docker compose restart backend

# 重新构建并启动（仅 backend）
docker compose up -d --build backend

# 停止所有服务
docker compose down

# 停止并删除数据卷（谨慎！会清空 Redis 数据）
docker compose down -v
```

### 7.2 日志查看

```bash
# 容器日志
docker compose logs --tail=50 -t backend

# 应用日志（在容器内）
docker exec -it gaking-backend tail -100 /app/logs/app.log

# 复制日志到宿主机
docker cp gaking-backend:/app/logs/app.log /tmp/backend-app.log
```

### 7.3 备份与恢复

```bash
# 备份 Redis
docker exec -it gaking-redis redis-cli -a '<密码>' --rdb /tmp/redis-dump.rdb
docker cp gaking-redis:/tmp/redis-dump.rdb /data/backups/redis-$(date +%Y%m%d).rdb

# 备份 .env 配置
cp /data/apps/gaking/backend/.env.production /data/backups/env-$(date +%Y%m%d).bak
```

## 八、常见问题排查

### 8.1 容器启动后立即退出

```bash
# 查看容器退出日志
docker compose logs backend

# 常见原因：
# 1. alembic 迁移失败 → 检查 MySQL 连通性
# 2. Redis 连接失败 → 检查 REDIS_PASSWORD 配置
# 3. 端口被占用 → 检查 3003 端口是否被占用
```

### 8.2 健康检查失败

```bash
# 查看 healthz 端点
curl -s http://localhost:3003/healthz

# 查看 readyz 端点（详细信息）
curl -s http://localhost:3003/readyz | python3 -m json.tool

# 如果 MySQL 不可达：
# 1. 检查 .env.production 中 DB_HOST 配置
# 2. 检查服务器到 MySQL 的网络连通性
# 3. 检查 MySQL 账户权限
```

### 8.3 商品/订单拉取失败

```
# 检查喵有券日志
docker compose logs backend | grep -i "miaoyouquan\|miaoyou"

# 常见原因：
# 1. 喵有券 IP 白名单未配置 → 联系喵有券配置
# 2. 喵有券 Token 过期 → 检查 MIAO_QUAN_TOKEN
# 3. 喵有券 API 服务不可用 → 等待恢复
```

### 8.4 定时任务未执行

```bash
# 检查定时任务调度器日志
docker compose logs backend | grep -i "scheduler\|task"

# 确认 SCHEDULER_ENABLE=true
grep SCHEDULER_ENABLE /data/apps/gaking/backend/.env.production

# 查看定时任务运行记录
# 调用 ops-monitor API 查看
```
